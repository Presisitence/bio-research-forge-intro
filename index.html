Bio Research Forge · MiniMax Code 社区插件 · v0.1.0

从一句问题，到一份能交的结果。

面向生命科学——植物、微生物、医学与临床——的 Agent Plugins 1.0 插件：12 个技能 + 3 个本地 MCP，把研究设计、公共数据查询、组学分析、统计、出图、写作、可复现性和独立审查，串成一条有边界、可追踪的工作流。

公共查询走只读白名单，每次回包都带来源 URL 与检索时间；本地表格不上传，R 在本机出图，缺依赖只报状态、不崩溃。

一套流程，四个阶段。

它不是把数据库链接堆在一起，而是给每个阶段一个技能、一份检查清单和一个停止条件：先判断问题能不能做，再决定查什么、怎么算、图怎么出、结论能写到哪一步。

→

从问题到流程

总控技能先判断任务类型，再路由到设计、数据、分析、写作或审查；每个技能写清输入、输出与停止条件，不把不同阶段揉成一团。

◎

只读的公共数据

UniProt、NCBI、InterPro、Ensembl、AlphaFold、RCSB PDB、STRING、JASPAR 按域名白名单查询；任意 URL、本地文件、凭据与专用数据门户一律拦截。

⌘

本地 R 出图

火山图、PCA、热图、箱线图、富集气泡图五类结果图。每次出图都附带 PNG（300 dpi）+ 矢量 PDF + plot-data.csv 三件套，图里的每个点都能回到表。

⊞

证据要分级

结论必须落在 Direct data / External evidence / Candidate evidence / Hypothesis 四级里。预测结构、文本挖掘分数、未读原文的引用，都不许写成直接证据。

◉

数据不出本机

表达矩阵只在本机读取，查询只发白名单域名；本地工具只调用已安装的 PyMOL / SnapGene / Cytoscape / Fiji，不静默安装、不接受任意命令。

✓

独立审查

交付前用 evidence-review 过 7 项检查：结论能否追溯、引用是否支持、正文数字与源表是否一致、图与数据/代码/图注是否一致、统计单位、是否夸大、是否含隐私。

InterProprotein/uniprot/Q9S7Q75 个蛋白条目；实验结构 0 个

医学 case 的边界同样写进 Review：表达下降不等于 TP53 突变或功能丧失，突变状态、IHC、测序都还没做。临床数据（患者标识、病历、影像）不进公共查询，插件也不做标识映射。

产物账本

21个产物文件：7 种图 × (PNG + PDF + plot-data.csv)
14项 Review 检查：两个 case 各 7 项，黄灯都写明原因
32条 SHA-256：两份 manifest，输入输出逐条可复核

黄灯是主动写出来的：样本量偏小、引用未读原文、富集与互作含文本挖掘、表达变化不等于功能验证；模拟数据与 padj 的正态近似也在报告第一段就声明。缺什么比多什么更难写，也更值钱。

两步就能跑。

插件是 Agent Plugins 1.0 的一个目录：plugin.json + 12 个 skills + 3 个 MCP。它不绑定某个客户端，MCP 走 stdio，任何支持 MCP 的宿主都能接。

git clone https://github.com/MiniMax-AI/MiniMax-Code-Plugins
cd MiniMax-Code-Plugins/plugins/Presisitence/bio-research-forge

需要 Node 18+。可选：NCBI_API_KEY 提高限流额度；RSCRIPT_EXE 指定 R 路径。

开始之前，你可能想知道。

这些图是真实数据吗？

图中的表达表是模拟数据，用来演示完整流程；两个 case 的公共数据查询都是真实执行的，带来源 URL 与检索时间。页面上所有材料都标注「示例数据（模拟）」，没有使用任何未发表研究数据。

医学和临床数据也能用吗？

能。人的 TP53 和拟南芥的 FLC 走的是同一组白名单接口：UniProt、InterPro、AlphaFold、NCBI、Europe PMC、JASPAR、STRING，换掉的只是查询串和物种编号。临床数据（患者标识、病历、影像）不进入公共查询，本地表也不上传，插件不做标识映射。

一定要装 R 吗？

只有本地出图需要 R 和 jsonlite / ggplot2 / pheatmap / ggrepel 四个包。没装时状态接口会返回缺失清单，公共查询和文本类技能照常可用。

数据会被上传吗？

不会。表达矩阵在本机读取、在本机渲染，输出也落在本机目录；插件没有遥测，查询白名单只放行公开数据库域名，任意 URL 和本地文件读取都会被拦截。

能在 MiniMax Code 之外用吗？

可以。它是 Agent Plugins 1.0 + MCP 的组合，MCP 通过 stdio 提供服务，不绑定特定客户端；换宿主只需要重新挂载 3 个 MCP 服务。

结果能直接写进论文吗？

图是出版级参数：300 dpi PNG、矢量 PDF、plot-data.csv 三件套。但统计与结论仍要过 evidence-review 和人工判断——插件负责把「证据到哪一步」写清楚，不替你下结论。
